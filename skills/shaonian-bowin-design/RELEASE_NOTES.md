## 本次修改

- Runtime index 脚本统一通过当前 Python 解释器启动，不依赖 ZIP 保留执行权限。
- 索引缺失、截断或 JSON 损坏时自动重建。
- 索引重建增加进程锁、临时文件、`fsync` 和原子替换，避免并发读到半文件。
- `query_runtime_index.py --limit` 限制为 `1..20`。
- 视觉附件增加 allowed-root 检查；本地文件校验通过不再等同于用户端交付完成。
- 最终图片必须取得平台可访问 URL，validator 才返回 `delivery_ready=true` 和 `markdown_image`。
- 页面截图缓存基线恢复为 30 天，稳定组件/模块保留 90 天。
- 缓存图片与 metadata 更新增加可恢复事务日志。
- “做完、直接产出、完整生成、一次完成、最终交付”及自动化/批处理直接进入 productionization。
- 新增只读性能基准脚本 `scripts/benchmark_runtime_indexes.py`。
- 新增 `requirements.txt`，明确运行时依赖 `PyYAML`。
- 发布 ZIP 排除 `__MACOSX`、临时事务文件、锁文件和 Python 缓存。
